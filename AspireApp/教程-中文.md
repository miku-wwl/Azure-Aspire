## 3. 核心概念：什么是 .NET Aspire？

**.NET Aspire** 是微软推出的**云原生应用开发框架**，解决微服务开发中的三个核心痛点：

| 痛点 | Aspire 的解决方案 |
|------|-------------------|
| 服务依赖管理复杂 | **声明式编排**：一行代码启动 Redis / PostgreSQL / RabbitMQ 等 |
| 服务间调用要硬编码地址 | **服务发现**：用服务名替代 IP:Port，自动解析 |
| 调试微服务困难 | **Aspire Dashboard**：统一查看所有服务的日志、追踪、指标 |

### 三个关键概念

```
1. App Host（编排器）
   └── 用 C# 代码声明你的应用由哪些服务组成
       例：builder.AddRedis("cache")  → 自动启动 Redis 容器

2. Integrations（集成包）
   └── 预配置的 NuGet 包，一行代码接入 Redis / PostgreSQL / RabbitMQ 等
       例：builder.AddRedisOutputCache("cache")  → 自动配置 Redis 缓存

3. Service Discovery（服务发现）
   └── 服务间通过名称互相调用，不关心 IP 和端口
       例：httpClient.BaseAddress = new("https+http://apiservice")
```

## 4. 深入 AppHost——编排大脑

**文件位置**：`AspireApp.AppHost/AppHost.cs`

```csharp
var builder = DistributedApplication.CreateBuilder(args);

// 1️⃣ 注册 Docker Compose 部署环境
builder.AddDockerComposeEnvironment("env");

// 2️⃣ 添加 Redis 缓存（自动拉取 redis 容器镜像）
var cache = builder.AddRedis("cache");

// 3️⃣ 添加 PostgreSQL 数据库 + PgAdmin 管理工具
var postgres = builder.AddPostgres("postgres")
    .WithPgAdmin();                          // 附带 Web 管理界面
var todosDb = postgres.AddDatabase("todosdb"); // 创建名为 todosdb 的数据库

// 4️⃣ 注册 API 服务（你的 .NET 项目）
var apiService = builder.AddProject<Projects.AspireApp_ApiService>("apiservice")
    .WithHttpHealthCheck("/health")          // 健康检查端点
    .WithReference(todosDb)                  // 注入数据库连接字符串
    .WaitFor(postgres);                      // 等 PostgreSQL 就绪后再启动

// 5️⃣ 注册 Web 前端（你的 .NET 项目）
builder.AddProject<Projects.AspireApp_Web>("webfrontend")
    .WithExternalHttpEndpoints()             // 对外暴露端口
    .WithHttpHealthCheck("/health")
    .WithReference(cache)                    // 注入 Redis 连接字符串
    .WaitFor(cache)                          // 等 Redis 就绪后再启动
    .WithReference(apiService)               // 引用 API 服务
    .WaitFor(apiService);                    // 等 API 就绪后再启动

builder.Build().Run();
```

### 逐行理解

| 代码 | 含义 |
|------|------|
| `builder.AddRedis("cache")` | 声明一个 Redis 资源，Aspire 自动拉取并启动 Redis 容器 |
| `builder.AddPostgres("postgres")` | 声明 PostgreSQL 资源，自动拉取并启动 PostgreSQL 容器 |
| `.WithPgAdmin()` | 附带启动 PgAdmin（Web 版数据库管理工具） |
| `.AddDatabase("todosdb")` | 在 PostgreSQL 中创建一个数据库 |
| `.WithReference(todosDb)` | 把数据库连接字符串注入到 API 服务的配置中 |
| `.WaitFor(postgres)` | 等待 PostgreSQL 健康检查通过后，才启动依赖它的服务 |
| `.WithHttpHealthCheck("/health")` | 配置健康检查路径 |
| `.WithExternalHttpEndpoints()` | 允许外部访问（生产部署时需要） |

### 关键设计理念

```
┌──────────────────────────────────────────┐
│         声明式 vs 命令式                   │
│                                          │
│  你只需要说"我要什么"                       │
│  Aspire 负责"怎么做到"                     │
│                                          │
│  AddRedis("cache")                       │
│    → 拉取镜像 → 启动容器 → 健康检查        │
│    → 注入连接字符串 → 生命周期管理          │
└──────────────────────────────────────────┘
```

## 5. ApiService——后端 API 服务

**文件位置**：`AspireApp.ApiService/Program.cs`

```csharp
var builder = WebApplication.CreateBuilder(args);

// ★ 这行是关键：自动接入服务发现、健康检查、OpenTelemetry
builder.AddServiceDefaults();

builder.Services.AddProblemDetails();   // 标准化错误响应
builder.Services.AddOpenApi();          // 生成 OpenAPI 文档

var app = builder.Build();

app.UseExceptionHandler();

if (app.Environment.IsDevelopment())
{
    app.MapOpenApi();                   // 开发环境暴露 /openapi/v1.json
}

// ─── 天气 API ───
string[] summaries = ["Freezing", "Bracing", "Chilly", "Cool",
                       "Mild", "Warm", "Balmy", "Hot",
                       "Sweltering", "Scorching"];

app.MapGet("/weatherforecast", () =>
{
    var forecast = Enumerable.Range(1, 5).Select(index =>
        new WeatherForecast(
            DateOnly.FromDateTime(DateTime.Now.AddDays(index)),
            Random.Shared.Next(-20, 55),
            summaries[Random.Shared.Next(summaries.Length)]
        )).ToArray();
    return forecast;
});

app.MapDefaultEndpoints();   // 注册 /health 和 /alive 健康检查端点
app.Run();
```

### 关键知识点

| 知识点 | 说明 |
|--------|------|
| `AddServiceDefaults()` | 来自 `ServiceDefaults` 项目，一行启用服务发现 + 弹性 + 健康检查 + OpenTelemetry |
| `MapDefaultEndpoints()` | 自动注册 `/health`（就绪检查）和 `/alive`（存活检查）端点 |
| `AddOpenApi()` | 生成 Swagger/OpenAPI 文档，开发环境可访问 `/openapi/v1.json` |
| Minimal API | .NET 6+ 的轻量级 API 写法，无需 Controller |

## 6. Web 前端——Blazor + 服务发现

### 6.1 启动配置 (`Program.cs`)

```csharp
var builder = WebApplication.CreateBuilder(args);

// ★ 接入服务默认配置
builder.AddServiceDefaults();

// ★ 一行代码接入 Redis 输出缓存
builder.AddRedisOutputCache("cache");

// Blazor 配置
builder.Services.AddRazorComponents()
    .AddInteractiveServerComponents();

// ★★★ 服务发现的核心 ★★★
builder.Services.AddHttpClient<WeatherApiClient>(client =>
{
    // 使用服务名 apiservice 而不是 http://localhost:xxxx
    // "https+http://" 表示优先 HTTPS，回退 HTTP
    client.BaseAddress = new("https+http://apiservice");
});
```

### 6.2 API 客户端 (`WeatherApiClient.cs`)

```csharp
public class WeatherApiClient(HttpClient httpClient)
{
    public async Task<WeatherForecast[]> GetWeatherAsync(
        int maxItems = 10,
        CancellationToken cancellationToken = default)
    {
        List<WeatherForecast>? forecasts = null;

        // 通过 HttpClient 调用 /weatherforecast
        await foreach (var forecast in httpClient
            .GetFromJsonAsAsyncEnumerable<WeatherForecast>(
                "/weatherforecast", cancellationToken))
        {
            if (forecasts?.Count >= maxItems) break;
            if (forecast is not null)
            {
                forecasts ??= [];
                forecasts.Add(forecast);
            }
        }

        return forecasts?.ToArray() ?? [];
    }
}
```

### 🔑 服务发现原理

```
传统方式：                          Aspire 方式：
http://localhost:5000/weather      https+http://apiservice/weather
       ↑                                    ↑
   硬编码端口                            服务名称
   改端口就挂                          永远不用改
```

**工作流程**：
```
Web 前端 ──→ 查找 "apiservice" ──→ Aspire 服务发现
                                        │
                                        ├─ 找到 apiservice 的地址
                                        ├─ 自动负载均衡
                                        └─ 自动重试（弹性策略）
```

## 7. ServiceDefaults——共享基础设施

**文件位置**：`AspireApp.ServiceDefaults/Extensions.cs`

这是 Aspire 的**秘密武器**，一个 `AddServiceDefaults()` 调用等于同时做了四件事：

```csharp
public static TBuilder AddServiceDefaults<TBuilder>(this TBuilder builder)
{
    // 1️⃣ OpenTelemetry：自动收集日志、追踪、指标
    builder.ConfigureOpenTelemetry();

    // 2️⃣ 健康检查：注册 /health 和 /alive 端点
    builder.AddDefaultHealthChecks();

    // 3️⃣ 服务发现：通过服务名自动解析地址
    builder.Services.AddServiceDiscovery();

    // 4️⃣ HTTP 弹性：自动重试、超时、熔断
    builder.Services.ConfigureHttpClientDefaults(http =>
    {
        http.AddStandardResilienceHandler();  // 标准弹性策略
        http.AddServiceDiscovery();           // HTTP 调用自动走服务发现
    });

    return builder;
}
```

| 功能 | 做了什么 | 你得到的好处 |
|------|----------|-------------|
| OpenTelemetry | 自动采集日志、追踪、指标，发送到 Dashboard | 不用手动集成 Application Insights / Jaeger |
| 健康检查 | `/health` + `/alive` 端点 | 容器编排器可以自动重启不健康的服务 |
| 服务发现 | `apiservice` → 自动解析为实际地址 | 服务可以随意扩缩容，不用改配置 |
| 弹性策略 | 自动重试 + 超时 + 熔断 | 网络抖动不影响用户体验 |

## 8. 运行与调试

### 8.1 开发模式运行

```powershell
# 进入 AppHost 目录
cd AspireApp\AspireApp.AppHost

# 启动（会自动拉取并启动 Redis、PostgreSQL 容器）
aspire run
```

运行后会发生：
```
1. Aspire 检查 Docker 是否运行
2. 拉取 redis:latest 镜像 → 启动 Redis 容器
3. 拉取 postgres:latest 镜像 → 启动 PostgreSQL 容器
4. 启动 PgAdmin 容器（如果配置了 WithPgAdmin）
5. 编译并启动 ApiService 项目
6. 编译并启动 Web 项目
7. 自动打开 Aspire Dashboard（浏览器）
```

### 8.2 Dashboard 功能

| 页面 | 功能 |
|------|------|
| **Resources** | 查看所有服务的拓扑图、状态、端点 |
| **Console Logs** | 实时查看每个服务的控制台输出 |
| **Structured Logs** | 结构化日志查询（支持筛选） |
| **Traces** | 分布式追踪（查看请求在各个服务间的流转） |
| **Metrics** | 指标仪表盘（CPU、内存、请求数等） |

### 8.3 访问服务

| 服务 | 地址 |
|------|------|
| Web 前端 | `https://localhost:xxxx`（Dashboard 中查看具体端口） |
| API 服务 | `https://localhost:xxxx/weatherforecast` |
| PgAdmin | `http://localhost:xxxx`（Dashboard 中查看） |
| Dashboard | `https://localhost:xxxx`（自动打开） |

## 9. 部署到生产环境

### 9.1 生成部署产物

```powershell

cd AspireApp

# 生成 Docker Compose 部署文件
aspire publish --output-path ./publish-output
```

产物：

### 9.2 部署

```powershell

# 方式二：手动使用 Docker Compose

```

```powershell
# Aspire CLI
aspire destroy

# 或手动
docker compose down -v
```
